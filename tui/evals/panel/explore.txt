# Explore-first cases (#416), in cases.txt's format, run with --cases. Each has
#   explore: <a folder under fixtures/>
# which the rig copies to a temp dir and uses as the pane's path; the write then
# reads it through the read-only profile. --no-explore runs the same cases with
# the same path and the text call, for the comparison.
# Each request needs a function name the screen does not show: only a read finds it.

=== explore-vat-cent
kind: bug
window: work · bash · .
explore: invoicer
expect: write
must: round_cents; money.py
must_not: def round_cents; quantize; ROUND_HALF_UP
note: the truncation is in round_cents; a rounding mode or quantize is the agent's fix
--- screen
$ invoicer total --net 19.99 --vat 19
23.78
$
--- request
the total is a cent short, it should be 23.79. fix it
