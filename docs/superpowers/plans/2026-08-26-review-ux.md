# Review popup UX — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** make the `prefix r` comment loop usable by a human who did not write it: `^E` opens an editor that works, a pinned comment can be edited in place, the diff preview carries line numbers and marks the row under the cursor, the list rows line up, the legend is grouped, the confirm pickers say what they mean, and one key copies a file plus its diff for pasting into another agent.

**Architecture:** every change stays inside the two scripts that already own the popup. `scripts/tmux-review` gets one editor chain (`editor_cmd`) shared by `^E` and `^S`, a `seed_comment` reader over `lib/review-store.sh` so `^E` on a commented row edits instead of appends, a `--copy` subcommand piped into `tmux load-buffer -w`, and a rebuilt display field in `mark_rows` (padded `path:line`, one coloured sign, a space after the marker). `scripts/tmux-open-path --preview-diff` gains a prefix-only awk gutter (old and new line numbers, delta's two columns) and an optional third argument that paints `▶` on one line after the cache, so the row's `+{5}` preview offset and the memo cache key stay valid. `--lines` output and its eight goldens are untouched: the display is rebuilt from fields 1-3, the anchor fields never move.

**Tech Stack:** bash 4+, tmux ≥ 3.3 (`load-buffer -w` ≥ 3.2), fzf 0.44.1 (`execute`, `preview-up/down`, `--color` names `border`/`scrollbar`; no `transform`, no `--highlight-line`), git, POSIX awk with `match`/`RSTART` (mawk here). No new dependency.

**Spec:** `docs/superpowers/research/2026-08-26-review-ux/` (README = root causes; `layout-survey.md` = the three mockups and verdict (a); `fzf-0.44.md`; `screen-critique.md` = the ranked defects). The owner's answers: `^Y` copies the full file then its diff; "mark the text" means mouse-copy from the preview (shift+drag, documented), not a range comment; no per-row copy key.

**Branch:** `feat/review-ux`, worktree `~/.cache/cockpit-wt/review-ux`, off master `0b240b6`. The shared checkout `~/.tmux/plugins/tmux-cockpit` is on another session's branch `fix/teammate-idle-wake` (TeammateIdle → wake; `^x` in the fleet queue), which edits `fleet_queue()` and appends to `tests/run.sh`: rebase onto master before the merge in Task 8 and expect a trivial append conflict in `tests/run.sh`. Its stray files `b`/`x` are not ours.

## Ponytail audit — asked for, and what this plan does instead

| asked for | verdict | why |
|---|---|---|
| diff-first layout (survey mockup b) | **skip** | context lines become rows and the list stops being a queue of unread changes; fzf 0.44 cannot skip rows. |
| side layout (mockup c) / `^/` cycling right→down→hidden | **skip** | unusable at 80 columns; the down layout with a gutter answers the same complaint. |
| per-file group rows with churn | **skip** | fzf has no unselectable row; a selectable non-anchor is a new special case in `attach`. |
| `F1` help screen, one-line legend | **replace** | three grouped lines fit 90 columns each and truncate from the least important end at 80; nothing to open. `?` stays typeable (`??` is the question convention). |
| range comments `## path:a-b` via `--multi` | **skip** | the owner meant copying text; the grammar keeps accepting ranges for a later ask. |
| `alt-y` copy the cursor row | **skip** | the owner said no. |
| `--no-mouse` so plain drag selects | **skip** | a tmux popup has no copy mode, so plain drag cannot select there whatever fzf does; shift+drag is the terminal's own selection and already works. Loses wheel scroll for nothing. |
| `xclip` fallback for the copy key | **skip** | `tmux load-buffer -w` pushes OSC 52 (`set-clipboard on` in the owner's config) and fills the tmux buffer for `prefix ]`. |
| fixed 40-column `path:line` field like `fleet_queue` | **replace** | one awk already reads every row; it measures the widest `path:line` and pads to it (cap 48), so a short review is not 30 spaces wide. |
| `▶` by feeding the row into the preview's cache key | **replace** | a post-cache `awk 'NR == n'` on the way out; the memo stays keyed on content only. |
| `@cockpit_review_editor` | **replace** | the existing `@cockpit_editor` → `$VISUAL` → `$EDITOR` → `vi` chain, in one function both `^E` and `^S` call. |
| `--edit-existing` subcommand | **replace** | the same `--edit` branches on "nothing typed and the row has comments". |
| a picker for "nothing to delete" | **replace** | one `tmux display-message`. |

```bash
# The one editor chain, shared with ^S's "edit the batch": the path picker's
# @cockpit_editor first, then the environment, then vi.
editor_cmd() {
    local ed
    ed=$(tmux show-options -gqv @cockpit_editor 2>/dev/null)
    printf '%s\n' "${ed:-${VISUAL:-${EDITOR:-vi}}}"
}

edit_comment() {              # <store> <path> <line> <fragment> <query> <dir>
    local store=$1 path=$2 line=$3 fragment=$4 query=$5 dir=$6 tmp ed
    [ -n "$path" ] && [ -n "$store" ] || return 0
    # ^E on the cap row would otherwise open the editor and then discard the paragraph.
    [ "$path" != "$CAP_SENTINEL" ] || return 0
    # fzf's execute() lends stdin the tty but leaves stdout on the pipe
    # run_loop captures (resnap's rule); vi refused that pipe and ate keys.
    [ -t 0 ] && [ ! -t 1 ] && exec >/dev/tty 2>&1
    tmp=$(umask 077; mktemp "${TMPDIR:-/tmp}/cockpit-review-edit.XXXXXX") || return 0
    [ -n "$query" ] && printf '%s\n' "$query" > "$tmp"
    ed=$(editor_cmd)
    # shellcheck disable=SC2086
    $ed "$tmp"
    attach "$store" "$path" "$line" "$fragment" "$(cat -- "$tmp")" "$dir"
    rm -f -- "$tmp"
}
```

# What another agent needs to discuss a change: the file as it stands, then
# the diff that got it there. Both to stdout; the bind pipes it to the clipboard.
copy_mode() {                 # <dir> [path]
    local dir=$1 path=${2:-}
    [ -n "$dir" ] || return 0
    if [ -z "$path" ]; then tree_diff "$dir"; return 0; fi
    [ "$path" != "$CAP_SENTINEL" ] || return 0
    if [ -f "$dir/$path" ]; then
        printf '### %s\n' "$path"; cat -- "$dir/$path"; printf '\n### diff %s\n' "$path"
    fi
    tree_diff "$dir" -- "$path"
}
